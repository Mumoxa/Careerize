## External public sources to add before publishing demand or formal qualification claims

These are target categories, not yet loaded source records:

- Stats SA labour-market publications for employment/demand context.
- SAQA/NQF records for qualification framework mapping.
- DHET and official institution sources for public universities and TVET colleges.
- SETA sector skills plans and learnership/apprenticeship information.
- Verified employer/practitioner interviews with consent for real story content.

## Rule

Careerize should stay away from detailed salary information for now. No Careerize page should display salary numbers, salary bands, demand strength, qualification eligibility or employment outcomes unless the founding team explicitly decides to add that data later and the underlying record has a source URL, access date and confidence score. The default product pattern is qualitative earning-potential insight, not pay-detail publishing.
